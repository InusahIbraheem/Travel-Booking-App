## ✨ Key Features & Experience Highlights

- **3D World Voyager Onboarding**: Multi-perspective globe animations and curated expedition buckets.
- **Interactive Destination Compass**: Top attractions, travel advisories, seasonal weather, and traveler ratings.
- **Flight & Boarding Pass Hub**: Real-time seat selectors, boarding countdowns, gate updates, and QR tickets.
- **Curated Itinerary Planner**: Multi-day trip schedules, landmark bookmarking, and local tour booking.
- **Verified Designer Branding**: Handcrafted with `@inusah_ibraheem` designer branding on every booking pass.

## 🎨 Design System & Visual Tokens

- **Theme & Aesthetics**: Aero Sky Blue & Ocean Navy
- **Primary Accent**: `#0284C7`

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (version 3.19.0 or higher recommended)
- [Dart SDK](https://dart.dev/get-dart)
- Android Studio / VS Code with Flutter Extension
- An active Android/iOS emulator or connected physical device

### Installation & Run

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/inusah-ibraheem/flutter-3d-ui-suite.git
   cd "flutter-3d-ui-suite/Travel Booking UI App"
   ```

2. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the Application**:
   ```bash
   flutter run
   ```
